# 架构设计

```text
工具已有的说明文件 ──告诉助手怎样查写──→ 终端命令
                                             │
                               识别个人目录和当前项目
                                             │
                       查相关行 / 写一条已确认的经验
                              ↙                    ↘
                      项目 Markdown             全局 Markdown
                              ↓                    ↓
                       项目已有 Git              个人记忆 Git
```

| 分层 | 对应代码 | 做什么 |
| --- | --- | --- |
| 命令入口 | `cmd/mem`、`internal/cli` | 处理用户输入，展示结果或迁移提示，不触碰厂商的原生记忆。 |
| 范围与存储 | `internal/workspace`、`internal/memory` | 找到当前仓库、阻止路径越界、保存与检索原文。[模块设计](模块设计/记忆读写.md) |
| 工具接入 | `internal/integration` | 找到有效的说明文件，预览、检查后仅维护自己的一小段用法。[模块设计](模块设计/工具接入.md) |

添加、查询不经过任何模型。`mem init` 才会写工具说明；`mem migrate` 只输出提示词。各工具之间从不直接通信。权限由当前操作系统用户和客户端自身决定：在同一账号下运行的助手有可能读取同一份个人资料，这两个范围不提供用户间的安全隔离。
