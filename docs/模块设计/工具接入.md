# 工具接入

模块定位：让能执行终端命令的编程助手知道怎样共用记忆。对应代码：`internal/integration`、`internal/cli/migrate.txt`。所属：[M0](../roadmap.md#m0)、[M1](../roadmap.md#m1)、[M2](../roadmap.md#m2)、[M3](../roadmap.md#m3)。当前状态：本地接入已完成，真实模型接力验证进行中；下一版体验未实现。更新时间：2026-11-21。

**职责与边界。** 只改用户选择范围里的说明文件，只教查、记和区分范围。不会注册插件、后台进程、协议服务器或改变厂商记忆开关。[调研和官方出处](../调研/主流编程助手的记忆.md)。

**结构与数据流。** 初始化先收集目标并预检，`--dry-run` 只显示计划。正式运行准备全局 Git 和记忆目录，再写说明。标记不成对、说明不是 UTF-8 文本或路径有符号链接时停下。现有规则保留；重复运行不再写相同内容。运行中遇到文件系统错误可能只完成部分文件，修正后可重跑。

**当前入口。** 项目根 `AGENTS.md` 供 Cursor、Codex、OpenCode、Devin Local 等读取。Claude 的全局 `CLAUDE.md` 首行导入同目录 `AGENTS.md`；项目已有 Claude 专用说明时，在项目根明确导入。Codex 尊重 `CODEX_HOME` 和优先的非空覆盖说明。Gemini 用默认 `~/.gemini/GEMINI.md`；Copilot 可加 `.github/copilot-instructions.md`，旧 Windsurf 可加 `.windsurf/rules/smem.md`。OpenCode 使用全局说明；已有 Claude 全局回退则保留，并给出提示。若项目原先只有 `CLAUDE.md`，新增 `AGENTS.md` 会改变 OpenCode 的项目回退，预览会提醒检查旧约定。Aider 手动用只读上下文文件。不在 Git 项目时，单靠项目说明接入的客户端需进入仓库再初始化。

**关键决策。** 预览不访问旧记忆。迁移只给提示词，旧助手先清点自己能读的内容并分清隐私/范围，用户确认后才逐条记入；权限不足只列候选，不尝试绕过。生成的说明是给模型的提示，不提供强制执行保证。

**验证。** 接入测试检查首行导入、原文/换行保留、覆盖文件选择、二次无改动、预检失败不写、个人配置路径。命令接力测试覆盖独立进程和另一个项目。`scripts/check.ps1 -RealCodex` 还会确认真实 Codex 的启动提示含用法、无笔记原文。

**待扩展。** 用不含敏感信息的项目让 Claude 与 Codex 进行双向盲测；任务不提“记忆”和命令，分别记录查到、用对、串读或漏查。其他客户端逐一记录版本；只验证目录布局时不宣称端到端通过。

**下一版接入。** 各品牌仍共用一条简短用法，不把笔记贴进各家的配置。工具调用失败就向用户说明；禁止用原生私有记忆代替共享写入后报告成功。未识别品牌能粘贴同一段用法，受限环境按权限降级。M2 先跑现有版本留基线，M3 用同样条件复测并加入纠正和忘记；[功能清单](../功能清单.md)列出题面和过关标准。

**改动历史。** 2026-11-21：完成官方资料比对、兼容注入和隔离验证；Codex 原生提示输入检查通过。
