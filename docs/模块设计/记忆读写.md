# 记忆读写

模块定位：把长期经验存在本地并按需读取。对应代码：`internal/workspace`、`internal/memory`。所属：[M1](../roadmap.md#m1)、[M3](../roadmap.md#m3)。当前状态：两层存储及纠正、忘记、浏览已实现，助手主动使用单独验收。更新时间：2026-11-21。

**职责与边界。** 管两个范围的 UTF-8 Markdown；不读工具私有目录、其他项目、聊天记录或 Git 历史。

**结构与数据流。** 跟随最近的 Git 工作区标记找到项目根。新增项目记忆落入 `<项目>/.mem/memory/`；显式个人偏好落入 `~/.mem/memory/`。查询依次检索两个目录直接包含的普通 `.md` 文件，给出原文、位置和范围。不存在的目录视为空；读取错误单独报出。

**关键决策。** 新增单条笔记用不含正文的短文件名，旧版带标题的名字继续识别。添加相同现行正文时复用已有笔记。编号绑定范围根目录、文件名、条目位置和文件完整内容的一份摘要；不会根据外部传入的路径去改文件。每个范围各有一个很短的写锁，写入程序竞争同一锁；异常遗留锁时，确认没有操作仍在运行后才能移除空锁目录。原生编辑器不使用该锁，不建议边编辑同一文件边让助手更新。历史和跨设备同步交给 Git。

**当前实现。** 默认新增项目记忆，不在项目中拒绝默认写入。自动生成的文件整篇算一条，手写主题按非空正文行区分。普通查询完整短语优先，其次看实词覆盖，再以范围和位置稳定排序，最多五条；中文使用相邻字组合，英文忽略大小写。开工查询另给最多三条明确标记的常用约定。常用标记是 Markdown 第一行 `<!-- smem:always -->`；普通用户无须填写模板。浏览可按范围分页，查看单条给原文。没有外部模型保证近义词理解。

**验证。** `go test -race ./...` 覆盖跨仓库引用、手改后的旧引用、同句并发、纠正后再添加不重复、BOM/CRLF 主题只改目标行、范围分页、常用与相关的独立上限。Windows 用两个真实子进程验证同一旧版本至多一方能改；换新引用后还能继续写。

**待扩展。** 普通查询最多五条，不返回全部命中的精确数量；要看全库请分范围翻页。后续可给普通查询补上达到上限的提示。先观察真实笔记量，再决定是否需要可删除的索引。不承担自动过期或推送。

**如何改和忘。** 先查或列出确切条目，持引用操作。锁内重读并验证后原位更新；已被人改过、改名、跨项目或有歧义就停下，先重新读取。单条笔记保持原文件位置，更正后旧引用失效；主题文件只改删目标行。纠正成已经存在的另一条完整结论时不静默合并。删除影响当前文件，不抹除 Git、原生笔记或聊天历史。[用户操作](../功能清单.md)。

**改动历史。** 2026-11-21：两层存储从简单查写扩展到开工回忆、浏览和精确改删。
