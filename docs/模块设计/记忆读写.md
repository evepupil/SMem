# 记忆读写

模块定位：把长期经验存在本地并按需读取。对应代码：`internal/workspace`、`internal/memory`。所属：[M1](../roadmap.md#m1)、[M3](../roadmap.md#m3)。当前状态：M1 已完成，M3 未开始。更新时间：2026-11-21。

**职责与边界。** 管两个范围的 UTF-8 Markdown；不读工具私有目录、其他项目、聊天记录或 Git 历史。

**结构与数据流。** 跟随最近的 Git 工作区标记找到项目根。新增项目记忆落入 `<项目>/.mem/memory/`；显式个人偏好落入 `~/.mem/memory/`。查询依次检索两个目录直接包含的普通 `.md` 文件，给出原文、位置和范围。不存在的目录视为空；读取错误单独报出。

**关键决策。** 同样的内容生成相同文件名，带可读短语和内容摘要。先完成写入再发布文件，可避免并发生成半条或多条记录。原文件被人改过时不覆盖。无索引、无运行中的服务。跨设备时用户自己使用 Git；运行中的多个工作树也不偷偷互拷笔记。

**当前实现。** 默认新增项目记忆。跨项目偏好显式选择；不在项目中则拒绝默认写入。搜索词忽略英文大小写，全部词须在同一行命中；最多回五行，每行摘录最多 220 个字符加省略号。主题文件可直接手写。准确命中依赖用词，当前不支持同义词或跨行匹配。相同命令的去重对于未改名的自动生成文件有效。

**验证。** `go test ./internal/memory ./internal/workspace` 覆盖同词双范围、手改删除、同句并发、主题多行、写入边界；`go test ./cmd/mem` 以真实命令进程和临时 Git 仓库模拟交接。

**待扩展。** 有真实笔记量带来的性能问题后再测是否需要可删除的索引。不承担自动过期或推送。

**下一版设计，尚未实现。** [功能清单](../功能清单.md)定义用户侧行为。查找与浏览返回能定位原条目的引用，带范围和所读版本。单条笔记纠正后保留定位；人工主题文件只改能唯一定位的一段，其他段落保持原样。遇到手工改名、并发修改、范围不符或定位歧义时拒绝用旧引用覆盖。现有纯 Markdown 无需批量迁移即可查询，也不要求用户填写模板。常用约定用可选的明文标记；普通查询仍直接读文件，开工查询才同时返回约定和相关经验。明确区分当前库的删除和 Git 历史的保留。

**改动历史。** 2026-11-21：落地两层本地记忆和无索引搜索；补充下一版的纠正、忘记、浏览与查找设计。
