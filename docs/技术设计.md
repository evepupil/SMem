# 技术设计

| 选择 | 原因与代价 |
| --- | --- |
| Go 1.25+，仅标准库，编译成 `mem` 单文件 | 用户运行时不用装语言环境；类型由编译器检查，以 `go vet`、测试和并发检查做门禁。 |
| UTF-8 Markdown，本地逐行查找 | 新增、手改、删除都能马上查到，没有索引损坏和重建流程。只支持字面关键词，不推断近义词。 |
| 看到最近的 `.git` 目录或工作树标记确定项目 | 在子目录和 Git 工作树能用相同命令，多个独立项目的内容不混在一起。个人目录不可当默认项目库。 |
| 临时文件写完再以硬链接发布新文件 | 同时记下同一句话也不会互相覆盖；底层卷必须支持硬链接。限制会报错，原文件保留。 |
| 用系统 Git 建立个人记忆仓库 | 用户自己选择远端、共享时机和提交内容。项目目录沿用现有仓库，不再嵌套一个仓库。 |

编码目录和各层职责见[架构设计](架构设计.md)。默认优先 Windows 门禁；其他平台需独立实机测试。配置兼容性按[客户端调研](调研/主流编程助手的记忆.md)核对。
